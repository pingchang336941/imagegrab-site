它是干什么的

做电商上新最费时间的不是修图，是把图一张张弄下来。本扩展在商品详情页右下角加一个「获取图片」按钮：点一下，整页图片全部抓出来，集中预览 → 勾选 → 打包成一个 ZIP。一个商品几十张图，30 秒带走。

一键提取淘宝、天猫、京东、拼多多商品详情页，点一下抓整页图片。
自动过滤推荐位、买家秀、横幅、二维码、小图标自动排除，默认只留商品图。
统一转 PNGJPG / WebP / GIF 进来，PNG 出去，保留原分辨率与透明通道。
打包 ZIP勾选后打成一个压缩包，文件名自动按顺序编号。

怎么用

  1. 安装后打开商品详情页（淘宝 / 天猫 / 京东 / 拼多多）。
  2. 点页面右下角「获取图片」按钮；其他网站可点浏览器工具栏的扩展图标手动提取当前页面。
  3. 在画廊里预览、勾选需要的图片，点「下载选中」逐张保存，或点「打包 ZIP」一个压缩包带走。
